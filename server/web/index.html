Guess Market Server is running

This WAR hosts the Guess Market engine (exercise 3). The JavaFX client and the web client talk to the endpoints below with JSON responses.

MethodEndpointPurpose
POST/login?username=Log in by name (409 if the name is connected)
POST/logoutLog out
GET/meWho am I
POST/uploadUpload an events XML (multipart part "file")
GET/eventsAll events + version
GET/events/details?id=One event in depth
POST/events/open?id=Open an event (market maker)
POST/events/close?id=&winner=Close an event (market maker)
POST/events/buy?id=&option=&shares=Buy LMSR shares
POST/events/order?id=&option=&side=&price=&quantity=Submit an order-book order
GET/usersAll users + version
GET/users/detailsMy account, participations and ledger
POST/users/funds?amount=Load funds
GET / POST/chat?version= / /chat?text=Bonus chat
